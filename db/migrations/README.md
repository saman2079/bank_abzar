# Migration 0001 — PostgreSQL schema

این فایل ساختار اولیه دیتابیس را تعریف می‌کند: کاربران و نشست‌ها، OTP، آدرس‌ها، برندها، دسته‌بندی‌ها، محصولات، سبد، سفارش و اقلام سفارش، پرداخت، گردش انبار، مقالات، Audit Log و Rate Limit.

## قواعد داده

- تمام ستون‌های `*_toman` مبلغ صحیح به تومان هستند؛ در لایه اتصال به درگاه باید تبدیل به ریال صریح باشد.
- تاریخ‌ها با `timestamptz` نگهداری می‌شوند.
- قیمت و مشخصات محصول در `order_items` snapshot می‌شوند.
- رکوردهای سفارش، اقلام و گردش انبار به‌صورت پیش‌فرض با حذف فیزیکی پاک نمی‌شوند.
- `inventory_movements` دفتر گردش است؛ عملیات تجاری باید در تراکنش، همراه با به‌روزرسانی محصول و درج ledger انجام شوند.
- سشن‌ها توکن خام را نگه نمی‌دارند؛ فقط هش توکن باید در `sessions.token_hash` ذخیره شود.

## وضعیت فعلی و هشدار

این فایل فقط Migration SQL است؛ هنوز runner، اتصال برنامه به PostgreSQL، repositoryها یا سیاست اجرای Migration در برنامه وصل نشده‌اند. این فایل در این نشست روی دیتابیس اجرا یا اعتبارسنجی نشده است. پیش از استفاده عملیاتی باید روی PostgreSQL 16 تمیز اجرا و بررسی شود؛ اجرای مجدد مستقیم آن بدون rollback/نسخه‌بندی پشتیبانی نمی‌شود.

برای بررسی محلی پس از راه‌اندازی PostgreSQL می‌توان از `psql` استفاده کرد:

```bash
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f db/migrations/0001_initial_schema.sql
```

این دستور را فقط روی دیتابیس توسعه خالی اجرا کنید؛ برای Production، backup و رویه migration کنترل‌شده ضروری است.
