# وضعیت پیاده‌سازی بانک ابزار

تاریخ: ۱۴۰۵/۰۷/۲۳

## آنچه در این مرحله انجام شده

- تنظیم زبان سند HTML روی فارسی و جهت پایه RTL.
- جایگزینی عنوان و توضیحات پیش‌فرض Next.js با Metadata فارسی.
- تعریف Design Tokens پایه برای رنگ، سطح، متن، مرز و وضعیت‌ها.
- ساخت صفحه اصلی واکنش‌گرا با هویت بصری صنعتی، هدر، فرم جست‌وجو، Hero، دسته‌بندی‌ها، بخش راهنمای انتخاب و Footer.
- اضافه‌کردن حالت‌های focus قابل مشاهده، رعایت prefers-reduced-motion و چیدمان‌های موبایل.
- اصلاح .gitignore برای نگه‌داشتن .env.example در مخزن.
- حفظ شاخه اصلی بدون تغییر مستقیم.

## محدودیت مهم

این مرحله یک پایه بصری است؛ هنوز فروشگاه عملیاتی کامل نیست. دسته‌بندی‌های صفحه اصلی داده‌های ثابت نمایشی‌اند و مسیرهای لینک‌شده هنوز صفحه/Endpoint پیاده‌سازی‌شده را تضمین نمی‌کنند. جست‌وجو به دیتابیس وصل نیست. هیچ محصول، موجودی، قیمت، مشتری، سفارش یا پرداخت واقعی ساخته نشده است.

## وضعیت اعتبارسنجی

- نصب وابستگی‌ها: انجام نشده در این نشست؛ محدودیت شبکه npm در ممیزی قبلی ثبت شده است.
- ESLint: اجرا نشده.
- TypeScript: اجرا نشده.
- Next.js production build: اجرا نشده.
- تست واحد، یکپارچگی و E2E: اجرا نشده.
- بررسی بصری در مرورگر و دستگاه واقعی: اجرا نشده.
- آزمون امنیتی: اجرا نشده.

نباید این شاخه را آماده Production یا دارای تست موفق تلقی کرد.

## گام‌های بعدی

1. در محیطی با دسترسی به npm، نصب وابستگی‌ها و خواندن مستندات رسمی دقیقاً منطبق با Next.js نصب‌شده.
2. تثبیت تصمیم‌های استقرار، Session، Variant، رزرو موجودی، ارسال و پیامک.
3. انتخاب و اضافه‌کردن نسخه‌های سازگار Drizzle، PostgreSQL driver و Zod و به‌روزرسانی Lockfile از طریق package manager واقعی.
4. پیاده‌سازی Schema و Migrationهای نسخه‌بندی‌شده، سپس سرویس‌های دامنه و سیاست‌های دسترسی.
5. اتصال کاتالوگ، جست‌وجو، سبد و پنل‌ها به داده واقعی.
6. پیاده‌سازی ورود OTP با Provider واقعی و محدودیت نرخ.
7. سفارش، ledger انبار، رزرو موجودی، پرداخت قابل تعویض و Callback idempotent.
8. مقالات ساختاریافته، SEO پویا و سیاست کش خصوصی/عمومی.
9. تست‌های خودکار، CI، Docker و مستندات استقرار پس از تأیید سازگاری.
10. بازبینی نهایی تغییرات و تأیید مالک پروژه پیش از هر انتقال به شاخه اصلی.

## تصمیم‌های مالی و امنیتی که هنوز نهایی نیستند

- زمان رزرو و آزادسازی موجودی و سیاست COD
- نرخ و محدوده ارسال
- ارائه‌دهنده OTP و درگاه پرداخت
- میزبان Production و دیتابیس
- سیاست حذف/نگهداری داده و مدت نگهداری لاگ
