# وضعیت پیاده‌سازی بانک ابزار

تاریخ: ۱۴۰۵/۰۷/۲۳

## تغییرات ثبت‌شده روی شاخه پیاده‌سازی

- صفحه اصلی فارسی و RTL با طراحی واکنش‌گرا و Design Tokens اولیه.
- تنظیم Metadata فارسی و قواعد .gitignore برای فایل محیط نمونه.
- توابع مستقل دامنه برای انتقال وضعیت سفارش، تأیید پرداخت، رزرو/آزادسازی/نهایی‌سازی موجودی و محاسبه جمع سفارش.
- ابزارهای مستقل برای نرمال‌سازی عبارت فارسی، ارقام و شماره موبایل ایران.
- ابزارهای پولی با تومان به‌عنوان واحد داخلی و تبدیل صریح تومان/ریال.
- Migration SQL اولیه برای کاربران، OTP، نشست‌ها، آدرس‌ها، کاتالوگ، سبد، سفارش، پرداخت، دفتر انبار، مقالات، audit و rate limit.
- نمونه متغیرهای محیطی بدون Secret واقعی.
- Dockerfile چندمرحله‌ای، Compose محلی PostgreSQL، .dockerignore و GitHub Actions برای lint، TypeScript و build.
- مستندات وضعیت، قواعد migration و محدودیت‌ها.

## آنچه هنوز عملیاتی نیست

این شاخه هنوز فروشگاه کامل نیست و Production-ready محسوب نمی‌شود.

- توابع دامنه هنوز به repository دیتابیس یا APIهای واقعی وصل نشده‌اند.
- Migration نوشته شده، اما runner خودکار و اجرای واقعی آن ایجاد/تأیید نشده است.
- در این مرحله Drizzle، Zod، PostgreSQL driver و کتابخانه تست اضافه نشده‌اند؛ علت، عدم دسترسی نصب وابستگی‌ها و ناتوانی در به‌روزرسانی معتبر lockfile است.
- ورود OTP، Session middleware، RBAC واقعی، محدودیت نرخ عملیاتی، محصولات متصل به دیتابیس، سبد خرید، checkout، پرداخت واقعی، انبارداری تراکنشی، پنل مدیریت و مقالات هنوز کامل نشده‌اند.
- Compose و Dockerfile ایجاد شده‌اند ولی Build یا اجرای آن‌ها آزمایش نشده؛ برنامه هنوز اتصال دیتابیس را مصرف نمی‌کند.
- CI تعریف شده اما اجرا/موفقیت آن تأیید نشده است.

## اعتبارسنجی

- npm install / npm ci: اجرا نشده در این دور.
- ESLint: اجرا نشده.
- TypeScript: اجرا نشده.
- Next.js build: اجرا نشده.
- SQL migration: اجرا نشده روی PostgreSQL.
- Docker build / compose: اجرا نشده.
- تست واحد، یکپارچگی، E2E و آزمون امنیتی: اجرا نشده.

هیچ‌یک از موارد بالا را نباید موفق فرض کرد.

## گام بعدی فنی

1. فراهم‌کردن محیطی با دسترسی به npm و مستندات نسخه نصب‌شده Next.js.
2. اضافه‌کردن نسخه‌های سازگار Drizzle، driver، Zod و test runner و تولید lockfile واقعی.
3. اتصال migrationها به runner و ساخت repositories.
4. پیاده‌سازی auth/session/authorization و Rate Limit.
5. اتصال catalog/search/cart به PostgreSQL.
6. پیاده‌سازی checkout و رزرو/آزادسازی موجودی در تراکنش با idempotency.
7. پیاده‌سازی payment provider واقعی و callback verify.
8. پنل مدیریت، مقالات، SEO و upload امن.
9. تست‌های خودکار، اجرای CI، تست Docker و بررسی امنیت.
10. بازبینی و ارائه برای تأیید مالک؛ بدون انتقال خودکار به master.

## ریسک‌های باز

- زمان رزرو و سیاست COD باید با عملیات کسب‌وکار نهایی شود.
- هزینه و محدوده ارسال تعیین نشده است.
- سرویس پیامک و درگاه پرداخت به حساب و Secret واقعی نیاز دارند.
- میزبان Production و هزینه جاری بررسی نشده‌اند.
- برای schema و migration هنوز اجرای واقعی روی PostgreSQL انجام نشده است.
